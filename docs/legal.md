## What the projects ship, and what they never ship

They ship their own code (GPL-3.0-or-later) and data written or measured by the project:
feature flags, keyword lists, builtin names, argument counts and types, field names, hash
constants, counts measured on scripts. Each data entry records its source and its licence.

They never ship, in the repositories, the releases or the issue tracker:

- game scripts, whether shipped with the game or its mod tools, decompiled or dumped;
- Activision documentation text, mod-tools sources, headers or syntax files;
- executables, memory dumps, fastfiles, assets or anything extracted from them as files;
- name databases built from game data.

You point the tools at your own install, mod tools or dumps. Indexes and caches derived from them
stay on your machine. The tools make no network access and collect no telemetry.

The projects take no money tied to Activision's intellectual property, and they do not touch
online play, anti-cheat, injectors or online clients.

## Takedown requests

If you believe something in these repositories or releases infringes your rights, open an issue
titled "Takedown request" (or contact the maintainer privately through the address in the commit
history) with the file or release, the line range if any, and the reason. The material is
removed from the default branch and the releases while the request is reviewed, and the outcome
is recorded in the issue. History rewrites are done where the content requires it.
