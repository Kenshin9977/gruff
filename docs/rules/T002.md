# T002 misspelled-event

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a `waittill`, `waittillmatch` or `endon` (or a wrapper such as `waittill_any`) on a literal event name that no script notifies, that is not used as a string anywhere else, that the engine catalogue does not list (when there is one), and that is one edit away (two for names of nine letters or more) from an event some script notifies, or the engine does, **on a compatible receiver**: `level` events only match `level` notifies, entity events only entity notifies, and `self` matches either.

Unlike [T001](T001.md) it works without the engine catalogue, because it only reports names that look like a typo of a known one. Names under five letters are not judged. Numbered and plural families (`wave1`/`wave2`, `goal`/`goals`, `move_done`/`movedone`) are naming variants, not typos.

When T001 reports a site (complete engine catalogue), T002 stays silent there: T001's message carries the suggestion.

## Measurements

On the local corpus of 20 games (each corpus folder checked on its own, BO3 and BO1 mod tools apart from their dumps), 2026-11-06:

| | reports | true typos | false |
|---|---|---|---|
| without engine catalogues | 74 | 47 (64%) | 27 |
| with the 13 engine catalogues (`gruff-data/events/`) | 67 | 48 (72%) | 19 |

The catalogues remove 9 false reports, all engine events (`"enter_vehicle"` x3 on WaW, `"grenade_flee"` x2 and `"goal_changed"` on BO1, `"player_pushed"` x2 and `"state_changed"` on Advanced Warfare), and add two, because an engine event can be the suggestion: one true (`"grenade_launncher_fire"`, WaW) and one false (`"veh_heightmesh_min"` against the engine's `"veh_heightmesh_max"`, BO2).

True reports: dead `endon`s and waits on `"disconnnect"`, `"disconect"`, `"diconnect"`, `"deaht"`, `"trgger"`, `"game_eneded"`, `"entiydeleted"`, `"deatchcard_timedout"`, `"near_goar"`, `"death_or_disconnet"`; and notify/wait mismatches where the notifier is the misspelled side (`"turret_handluse"` in five IW games, `"gunhip_storing_fov"`, `"bot_payloadr_think"`, `"endGivUpProgressBar"`). The 19 false ones: engine events the catalogues do not list yet (`"animsdone"` x4 on Ghosts and Advanced Warfare, `"enter_vlobby"`, BO2's `"grenade_flee"`), and unrelated names one or two edits apart (`"enemy_spooked"`/`"enemy_spotted"` x2, `"stop_thinking"`/`"stop_ticking"`, `"teleportEnd"`/`"teleported"`, `"restartWeaponVFX"`/`"startweaponvfx"`, `"monkeys_grabbed"`/`"money_grabbed"`, `"light_off"`/`"lights_off"` x2, `"end_sequence"`/`"new_sequence"`, `"weapon_pickedup"`, `"stop_look"`, `"veh_heightmesh_min"`).

Measured again on 2026-11-11, after the suggestion was tightened to **one edit** whatever the name's length (it allowed two from twelve characters up): 67 reports to 54, over 39 distinct name pairs to 27. The twelve pairs that went are, eight of them, from the false list above — `"enemy_spooked"`/`"enemy_spotted"`, `"stop_thinking"`/`"stop_ticking"`, `"monkeys_grabbed"`/`"money_grabbed"`, `"veh_heightmesh_min"`/`"_max"`, `"restartWeaponVFX"`/`"startweaponvfx"`, `"weapon_pickedup"`, `"end_sequence"`/`"new_sequence"`, BO2's `"grenade_flee"` — and four were two-edit reports this measurement cannot judge either way (`"artillary_barriage"`/`"atrillery_barriage"`, where both spellings are wrong, `"death_or_disconnector"`, `"train_shutdown"`/`"tram_shutdown"`, `"richtofen_sq_complete"`). Every true report of the list above is a single edit: a letter doubled, dropped, swapped or mistyped once. Two edits in a long name is nearly always two different words sharing a prefix.

So roughly 44 true in 54, about 81%, against 72% before, at the cost of up to four true reports.

**It stays in preview.** What is left divides in two. Five reports are engine events no catalogue lists yet (`"animsdone"` x4, `"enter_vlobby"`): the rule is right that nothing in the workspace notifies them, and only the missing catalogues can settle it, which is a data gap and not a rule to tune. Discounting those, the rule's own precision is about 90%. The others (`"light_off"`/`"lights_off"`, `"teleportEnd"`/`"teleported"`, `"stop_look"`/`"stop_loop"`) are single-edit pairs of two real names, which no edit-distance rule can separate.

## Why

A misspelled event name fails silently: the wait never ends, or the `endon` never fires.

## Example

```gsc
function a()
{
    level notify( "round_started" );
}

function b()
{
    level waittill( "round_startd" );   // T002 did you mean "round_started"?
}
```

## How to suppress

`// gsc: ignore[T002]` on the line, or `ignore = ["T002"]` in `gruff.toml`.
