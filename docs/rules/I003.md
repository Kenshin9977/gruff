# I003 unresolved-import

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a `#using`, `#include`, `#insert` or `#inline` of a file the workspace does not have, when the target's folder holds other files.

It runs only when the game's scripts are a library root (`--library`, or `library` in the configuration): without them every stock import would be missing.

## Why

The compiler refuses it: "Compile error processing "using" file - file not found" and "Couldn't open file" for `#insert` (`lint_using_missing.gsc`, `lint_insert_missing.gsc`). After gscode's `UsingNotFound` and `InsertNotFound` (GPL-3.0).

## Example

```gsc
#using scripts\shared\util_shard;  // I003: typo
```

## How to suppress

On the line (or on its own line just above it):

```gsc
#using scripts\mymod\generated;  // gsc: ignore[I003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[I003]`. In `gruff.toml`:
`ignore = ["I003"]`, or `[check.per-file-ignores]` with `"pattern" = ["I003"]`.
