# D002 missing-function-keyword

## What it does

In games where function declarations need the `function` keyword (BO3 and later), reports declarations without it.

## Why

The parser accepts the syntax of every Call of Duty game; the dialect check then reports what the selected game (`--game`, or `game` in `gruff.toml`) does not have. The game's compiler would reject it.

## Example

```gsc
// gruff check --game t7
main()   // D002
{
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
main()  // gsc: ignore[D002]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D002]`. In `gruff.toml`:
`ignore = ["D002"]`, or `[check.per-file-ignores]` with `"pattern" = ["D002"]`.
