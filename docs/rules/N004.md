# N004 script-arg-count

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a call to a script function with more arguments than it declares (no `...`). Fewer is fine: the missing parameters are undefined. Every function of that name in the namespace must declare the same count, else nothing is said.

## Why

The extra arguments are never read: a leftover from a changed signature, or a call meant for another function. The BO3 linker accepts it (`lint_too_many_args.gsc`). After gscode's `TooManyArguments` (GPL-3.0).

Measured: 63 distinct findings in the shipped sources (BO3 15, BO1 31, WaW 8...); every one sampled passes an argument the callee does not declare.

## Example

```gsc
function spawn_at( origin ) { }
spawn_at( origin, angles );  // N004
```

## How to suppress

On the line (or on its own line just above it):

```gsc
spawn_at( origin, angles );  // gsc: ignore[N004]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N004]`. In `gruff.toml`:
`ignore = ["N004"]`, or `[check.per-file-ignores]` with `"pattern" = ["N004"]`.
