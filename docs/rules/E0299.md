# E0299 parser-stuck

## What it does

The parser could not make progress at this token and skipped it. This is a parser bug: please report it with a reduced file you wrote yourself.

## Why

The file does not parse, so the game's compiler rejects it. The parser recovers and keeps going, so later diagnostics in the same file still mean something, but fix the first error first.

## Example

Any input that triggers it is a bug report.

Syntax errors can be suppressed like any other code, but there is rarely a good reason: the game will not load the file.

## How to suppress

On the line (or on its own line just above it):

```gsc
...  // gsc: ignore[E0299]
```

For a whole file, anywhere in it: `// gsc: ignore-file[E0299]`. In `gruff.toml`:
`ignore = ["E0299"]`, or `[check.per-file-ignores]` with `"pattern" = ["E0299"]`.
