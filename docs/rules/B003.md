# B003 dev-only-builtin

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a call to a debug builtin (type flag 1 in the catalogue: `line`, `print3d`, `box`, `println`...) outside a `/# #/` dev block.

## Why

The BO3 linker rejects these calls with "Dev only calls must be wrapped in a devblock". The rule is in preview while the flag's meaning is checked against more of the engine.

## Example

```gsc
function f()
{
    line( self.origin, self.origin + ( 0, 0, 64 ) );        // B003
    /# line( self.origin, self.origin + ( 0, 0, 64 ) ); #/  // fine
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
line( a, b );  // gsc: ignore[B003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[B003]`. In `gruff.toml`:
`ignore = ["B003"]`, or `[check.per-file-ignores]` with `"pattern" = ["B003"]`.
