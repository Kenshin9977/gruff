# E0203 nesting-too-deep

## What it does

Statements or expressions nest more deeply than the parser's limit. Real scripts never get there; generated or corrupted ones can.

## Why

The file does not parse, so the game's compiler rejects it. The parser recovers and keeps going, so later diagnostics in the same file still mean something, but fix the first error first.

## Example

```gsc
x = (((((((( ... ))))))));   // E0203 past a few hundred levels
```

Syntax errors can be suppressed like any other code, but there is rarely a good reason: the game will not load the file.

## How to suppress

On the line (or on its own line just above it):

```gsc
...  // gsc: ignore[E0203]
```

For a whole file, anywhere in it: `// gsc: ignore-file[E0203]`. In `gruff.toml`:
`ignore = ["E0203"]`, or `[check.per-file-ignores]` with `"pattern" = ["E0203"]`.
