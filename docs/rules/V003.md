# V003 read-only-assignment

## What it does

Reports an assignment (or `++`/`--`) to `.size`, to an engine global the profile makes a keyword (`self`, `level`, `game`, `anim`...), or to a local declared `const`.

## Why

The BO3 compiler refuses all three: a syntax error for `.size` and the globals, "Cannot assign values to a const variable" (`lint_size_write.gsc`, `lint_level_assign.gsc`, `lint_self_assign.gsc`, `lint_const_assign.gsc`). After gscode's `SizeIsReadOnly`, `CannotAssignToGlobalObject` and `CannotAssignToConstant` (GPL-3.0). Stable: a compiler error, with no finding in the shipped sources.

## Example

```gsc
a.size = 0;  // V003
level = undefined;  // V003
```

## How to suppress

On the line (or on its own line just above it):

```gsc
a.size = 0;  // gsc: ignore[V003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[V003]`. In `gruff.toml`:
`ignore = ["V003"]`, or `[check.per-file-ignores]` with `"pattern" = ["V003"]`.
