# S100 unused-suppression

## What it does

Reports a `// gsc: ignore[...]` or `// gsc: ignore-file[...]` comment, or one of its codes, that suppressed nothing, and codes that name no rule. Codes of rules that are not enabled for the file are not reported.

## Why

Stale suppressions hide the next real problem on their line. This is Ruff's RUF100.

## Example

```gsc
function f()
{
    wait 1;   // gsc: ignore[L001]   <- S100: nothing to suppress
}
```

## Fix

A **safe** fix removes the unused codes, or the whole comment when none is used.

A line comment cannot suppress S100; use `// gsc: ignore-file[S100]` or the configuration.

## How to suppress

On the line (or on its own line just above it):

```gsc
wait 1; // gsc: ignore-file[S100]  // gsc: ignore[S100]
```

For a whole file, anywhere in it: `// gsc: ignore-file[S100]`. In `gruff.toml`:
`ignore = ["S100"]`, or `[check.per-file-ignores]` with `"pattern" = ["S100"]`.
