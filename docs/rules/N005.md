# N005 duplicate-function

## What it does

Reports a function (or method) defined twice in one file, in the same namespace and class. Decompiler output is skipped.

## Why

The BO3 compiler refuses it: "Duplicated function name detected" (`lint_dup_func.gsc`). After gscode's `DuplicateFunction` (GPL-3.0). Stable: a compiler error, with no finding in the shipped sources.

## Example

```gsc
function init() { }
function init() { }  // N005
```

## How to suppress

On the line (or on its own line just above it):

```gsc
function init()  // gsc: ignore[N005]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N005]`. In `gruff.toml`:
`ignore = ["N005"]`, or `[check.per-file-ignores]` with `"pattern" = ["N005"]`.
