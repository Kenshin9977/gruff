# V004 division-by-zero

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports `/`, `%`, `/=` and `%=` by a literal zero.

## Why

A script error when it runs. The BO3 compiler accepts it (`lint_div_zero.gsc`). After gscode's `DivisionByZero` (GPL-3.0).

## Example

```gsc
ratio = hits / 0;  // V004
```

## How to suppress

On the line (or on its own line just above it):

```gsc
ratio = hits / 0;  // gsc: ignore[V004]
```

For a whole file, anywhere in it: `// gsc: ignore-file[V004]`. In `gruff.toml`:
`ignore = ["V004"]`, or `[check.per-file-ignores]` with `"pattern" = ["V004"]`.
