# D006 unavailable-builtin-call

## What it does

Reports the `builtin` call modifier (`builtin foo()`, which forces the engine function over a script function of the same name) in a game that does not have it (profile feature `builtin_call`).

## Why

The game's compiler rejects the file.

## Example

```gsc
builtin spawnstruct();   // D006 in a game without `builtin` calls
```

## How to suppress

On the line (or on its own line just above it):

```gsc
builtin spawnstruct();  // gsc: ignore[D006]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D006]`. In `gruff.toml`:
`ignore = ["D006"]`, or `[check.per-file-ignores]` with `"pattern" = ["D006"]`.
