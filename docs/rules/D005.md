# D005 unavailable-cast

## What it does

Reports a `(type)` cast such as `(int)x` in a game whose compiler has no casts (profile feature `casts`).

## Why

The game's compiler rejects the file. Casts exist in some later dialects and in community compilers; check the game selected with `--game` (or `game` in `gruff.toml`).

## Example

```gsc
n = (int)level.count;   // D005 in a game without casts
```

## How to suppress

On the line (or on its own line just above it):

```gsc
n = (int)x;  // gsc: ignore[D005]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D005]`. In `gruff.toml`:
`ignore = ["D005"]`, or `[check.per-file-ignores]` with `"pattern" = ["D005"]`.
