# B001 unknown-builtin

## What it does

Reports a bare call (`foo()`, or `ent foo()` for a method) whose name is neither a builtin of the game nor a function defined anywhere in the files being checked. It also reports a builtin called with the wrong shape (a method called without a receiver, or a function with one), and a builtin of the other VM (a CSC builtin in a `.gsc` file, or the reverse; `.gsh` headers accept both). When the name is close to a builtin it suggests it.

The builtin catalogue is `gruff-data/builtins/<game>.toml`, extracted from the game executable and matched by hash, so entries whose name is unknown still count. Without a catalogue for the game the rule is silent. Skipped: calls through pointers (`[[ f ]]()`), qualified calls (`ns::f()`), hashed names (`function_1a2b3c4d`), macros (any `#define` in the workspace, and upper-case names), and the catalogue's intrinsics (its `[[intrinsic]]` list: `isdefined`, `vectorscale`, and in the later games `endon`, `notify`, `waittill`...), which the compiler turns into opcodes.

The rule stays silent for a game whose catalogue is partial (`[coverage] complete = false`: an executable of the game was not extracted, or some entries have neither a name nor a hash, as in IW1, IW3, IW4, IW6, IW7, IW8, S1, H1 and T4). There a name missing from the catalogue may still be a builtin.

## Why

The game's linker rejects a call it cannot resolve, and a misspelled builtin is the most common reason. To keep false positives low, a name defined as a script function in any file of the workspace is never reported, so check the whole mod, with the game's scripts next to it when you have them.

## Example

```gsc
function f()
{
    e = spwan( "script_origin", self.origin );   // B001 unknown builtin function `spwan`; did you mean `spawn`?
    self iprintlnbold( "hi" );                   // fine: a builtin method
}
```

## Fix

When exactly one builtin is close, an **unsafe** fix renames the call (`--fix --unsafe-fixes`): it changes which function runs.

Script functions named like a builtin are never reported.

## How to suppress

On the line (or on its own line just above it):

```gsc
e = spwan( "script_origin", self.origin );  // gsc: ignore[B001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[B001]`. In `gruff.toml`:
`ignore = ["B001"]`, or `[check.per-file-ignores]` with `"pattern" = ["B001"]`.
