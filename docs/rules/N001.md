# N001 unresolved-script-function

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports `ns::f()`, `path\file::f()`, `&ns::f` and `::f()` that name no script function:

- `ns::f` when some file of the workspace declares namespace `ns` (else its scripts are simply not loaded) and `ns` is not a class;
- `path\file::f` when the file and everything it `#include`s are in the workspace (a path call reaches the functions the file includes) and none defines `f`;
- `::f` with a complete builtin catalogue that has no `f` either (`::f` may point at a builtin).

Decompiler output and hashed names are skipped.

## Why

The call names a script location, so no builtin can match: the game fails to link it. After gscode's `ScriptFunctionNotFound` (GPL-3.0).

Measured: 15 findings in the shipped sources; each names a function the corpus copy of the file does not define (BO3 `globallogic_ui::createweakpointwidget` lives in the campaign scripts the mod tools do not ship; WaW zombie maps call functions of later versions of `_zombiemode_*`). Accurate about the workspace; a finding is a real error when the workspace holds the game's full scripts.

## Example

```gsc
util::wiat( 1 );  // N001: util has no wiat
```

## How to suppress

On the line (or on its own line just above it):

```gsc
util::wiat( 1 );  // gsc: ignore[N001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N001]`. In `gruff.toml`:
`ignore = ["N001"]`, or `[check.per-file-ignores]` with `"pattern" = ["N001"]`.
