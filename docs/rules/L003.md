# L003 duplicate-case-label

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a `case` value a switch already has (integers by value, strings by their exact text) and a second `default:`. Decompiler output is skipped.

## Why

Only the first label can match, so the second branch is dead. The BO3 compiler refuses two `default` labels ("Switch statement has more than one default item specified", `lint_dup_default.gsc`) and accepts a repeated value (`lint_dup_case.gsc`). After gscode's `DuplicateCaseLabel` and `MultipleDefaultLabels` (GPL-3.0).

Measured: 1 finding in the shipped sources (BO3 `vehicle_shared.csc`, two `case 1:`), a real bug.

## Example

```gsc
switch ( level )
{
    case 1:
        low();
        break;
    case 1:  // L003
        high();
        break;
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
case 1:  // gsc: ignore[L003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[L003]`. In `gruff.toml`:
`ignore = ["L003"]`, or `[check.per-file-ignores]` with `"pattern" = ["L003"]`.
