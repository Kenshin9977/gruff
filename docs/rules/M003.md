# M003 duplicate-macro-parameter

## What it does

Reports a parameter name repeated in one `#define`.

## Why

Only one of the two can be substituted. The BO3 preprocessor refuses it (`lint_dup_macro_param.gsc`). After gscode's `DuplicateMacroParameter` (GPL-3.0). Stable: a compiler error.

## Example

```gsc
#define ADD( a, a ) ( a + a )  // M003
```

## How to suppress

On the line (or on its own line just above it):

```gsc
#define ADD( a, a ) ( a + a )  // gsc: ignore[M003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[M003]`. In `gruff.toml`:
`ignore = ["M003"]`, or `[check.per-file-ignores]` with `"pattern" = ["M003"]`.
