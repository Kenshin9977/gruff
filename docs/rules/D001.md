# D001 unavailable-feature

## What it does

Reports syntax the selected game lacks, naming the profile feature: `class` before BO3, `foreach` in CoD4, `?.` outside the games that have it...

## Why

The parser accepts the syntax of every Call of Duty game; the dialect check then reports what the selected game (`--game`, or `game` in `gruff.toml`) does not have. The game's compiler would reject it.

## Example

```gsc
// gruff check --game iw4
function f( a )
{
    foreach ( x in a ) { }   // D001 `foreach` is not available in iw4 (feature `foreach`)
}
```

Check that `--game` names the game the script is for; the dialect profiles live in `gruff-data/profiles`.

## How to suppress

On the line (or on its own line just above it):

```gsc
foreach ( x in a ) { }  // gsc: ignore[D001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D001]`. In `gruff.toml`:
`ignore = ["D001"]`, or `[check.per-file-ignores]` with `"pattern" = ["D001"]`.
