# L005 non-constant-case-label

## What it does

Reports a `case` label that is `undefined`, a variable, a call or a field. Labels that name a macro are left alone.

## Why

The BO3 compiler refuses them: "Switch case must be a string or integer type" (`lint_case_undefined.gsc`, `lint_case_variable.gsc`). `case undefined:` would never match anyway; test `isdefined()` before the switch. After gscode's `CaseUndefined` and `NonConstantCaseLabel` (GPL-3.0). Stable: a compiler error, with no finding in the shipped sources.

## Example

```gsc
switch ( x )
{
    case undefined:  // L005
        break;
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
case undefined:  // gsc: ignore[L005]
```

For a whole file, anywhere in it: `// gsc: ignore-file[L005]`. In `gruff.toml`:
`ignore = ["L005"]`, or `[check.per-file-ignores]` with `"pattern" = ["L005"]`.
