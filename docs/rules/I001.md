# I001 duplicate-import

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a `#using` or `#include` of a file the same directive already imported earlier in the file.

## Why

The second directive does nothing. The BO3 linker accepts it (`lint_dup_using.gsc`); the line is clutter that a merge or a copied header block leaves behind. After gscode's `DuplicateImportLint` (GPL-3.0).

## Example

```gsc
#using scripts\shared\util_shared;
#using scripts\shared\util_shared;  // I001
```

## Fix

A **safe** fix deletes the repeated directive with its line (`--fix`).

## How to suppress

On the line (or on its own line just above it):

```gsc
#using scripts\shared\util_shared;  // gsc: ignore[I001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[I001]`. In `gruff.toml`:
`ignore = ["I001"]`, or `[check.per-file-ignores]` with `"pattern" = ["I001"]`.
