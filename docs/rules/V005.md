# V005 useless-expression

## What it does

Reports a statement that computes a value and discards it: a comparison, an operation, a literal, a variable, a field read. Macros used as statements (`WAIT_SERVER_FRAME;`) are left alone.

## Why

It does nothing: usually `==` typed for `=`, or a call missing its `()`. The BO3 compiler refuses it (syntax error, `lint_useless_expr.gsc`, `lint_useless_cmp.gsc`). After gscode's `InvalidExpressionStatement` (GPL-3.0). Stable: a compiler error, with no finding in the shipped sources.

## Example

```gsc
level.round == 1;  // V005
```

## How to suppress

On the line (or on its own line just above it):

```gsc
a == b;  // gsc: ignore[V005]
```

For a whole file, anywhere in it: `// gsc: ignore-file[V005]`. In `gruff.toml`:
`ignore = ["V005"]`, or `[check.per-file-ignores]` with `"pattern" = ["V005"]`.
