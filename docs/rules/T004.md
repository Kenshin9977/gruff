# T004 missing-endon

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a function that

- is started only with `thread` (never called synchronously, never with `childthread`, never through a function pointer: a `childthread` inherits the `endon`s of the thread that starts it, measured in the BO4 and Cold War VMs), at least once on an expression naming a player (`player thread f()`, `players[ i ] thread f()`; `self thread f()` and other objects are allowed too), and never on `level`;
- contains an infinite loop (`while ( 1 )`, `for ( ;; )`) that it cannot leave (no `break`, `return` or `goto`) and that waits for time (`wait`, `waitframe`, `waitrealtime`);
- has no `endon` at all (any receiver, any event name: the rule does not guess which one ends the thread);
- uses no macro (which might hide the `endon`), and is not in a client script (`.csc`).

## Why it is in preview

Measured on the local corpus of 20 games: 79 reports, most of them in single-player campaign scripts (BO2's `maps/afghanistan*`, MWIII's campaign), where the player never disconnects and the level's end ends every thread, and in dev-only scripts (`_debug`, `_dev`). The multiplayer and zombies findings are real but minor (a HUD or weapon watcher left running after the player left). Client scripts (`.csc`) are not judged. A loop that only waits for the player's own notifies is not reported (freeing an object ends the threads waiting on it); a timed wait (`wait`, `waitframe`) is required. The engine catalogues do not change it (80 reports on 2026-11-06 with or without them, BO1 and BO3 sources and dumps checked together): the rule reads no event name.

## Why

`endon` is what ties a thread's life to its entity. A loop threaded on a player that never ends on `"disconnect"` keeps running after the player is gone, and then errors on removed-entity access or leaks script variables.

## Example

```gsc
function spawned( player )
{
    player thread hud_loop();
}

function hud_loop()   // T004
{
    while ( 1 )
    {
        self.hud_value = self.score;
        wait 0.5;
    }
}

function hud_loop_ok()
{
    self endon( "disconnect" );
    while ( 1 )
    {
        self.hud_value = self.score;
        wait 0.5;
    }
}
```

## How to suppress

`// gsc: ignore[T004]` on the function's line.
