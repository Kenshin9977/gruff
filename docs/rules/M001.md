# M001 macro-arg-count

## What it does

Reports a call of a function-like macro (`#define F( a, b )`) with another number of arguments than it has parameters (at least as many before a `...`). Every definition the file can see must agree, else nothing is said; `F()` for a one-parameter macro passes one empty argument and is accepted.

## Why

The preprocessor refuses it (BO3: "Illegal token", `lint_macro_arity.gsc`), as every C preprocessor does. After gscode's `WrongMacroArgumentCount` (GPL-3.0). Stable: a compiler error.

## Example

```gsc
#define DOUBLE( x ) ( ( x ) * 2 )
n = DOUBLE( 1, 2 );  // M001
```

## How to suppress

On the line (or on its own line just above it):

```gsc
n = DOUBLE( 1, 2 );  // gsc: ignore[M001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[M001]`. In `gruff.toml`:
`ignore = ["M001"]`, or `[check.per-file-ignores]` with `"pattern" = ["M001"]`.
