# N002 namespace-not-imported

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports `ns::f()` (games with `#namespace`) when neither the file nor any file it `#using`s declares namespace `ns`, though some file of the workspace defines `ns::f`.

## Why

The script that holds `ns::f` is not linked with this one. No shipped BO3 script does it (0 findings in the mod tools' sources). After gscode's `NamespaceNotImported` (GPL-3.0).

## Example

```gsc
function f()
{
    util::wait_network_frame();  // N002: no #using scripts\shared\util_shared
}
```

## Fix

An **unsafe** fix adds `#using <file>;` after the last `#using` (`--fix --unsafe-fixes`): it links another script.

## How to suppress

On the line (or on its own line just above it):

```gsc
util::wait_network_frame();  // gsc: ignore[N002]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N002]`. In `gruff.toml`:
`ignore = ["N002"]`, or `[check.per-file-ignores]` with `"pattern" = ["N002"]`.
