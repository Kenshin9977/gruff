# N003 private-function-call

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a call or reference to a function declared `private` in another file, from a namespace other than the function's.

## Why

Privacy is per namespace, as gscode models it (`PrivateAccessLint`, GPL-3.0); the BO3 linker does not check it at compile time (`lint_private_call.gsc` links), so the call fails when the game loads the script. Not measured in a VM yet: preview.

## Example

```gsc
zm_utility::private_helper();  // N003
```

## How to suppress

On the line (or on its own line just above it):

```gsc
other::hidden();  // gsc: ignore[N003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N003]`. In `gruff.toml`:
`ignore = ["N003"]`, or `[check.per-file-ignores]` with `"pattern" = ["N003"]`.
