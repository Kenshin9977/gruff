# M002 macro-redefined

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a `#define` of a name already defined, earlier in the file or by a header it `#insert`s, without an `#undef` in between. Definitions inside an `#if` region are left out: another configuration may skip them.

## Why

The BO3 preprocessor refuses a redefinition even with the same body: "Macro name already defined" (`lint_dup_macro.gsc`, `lint_dup_macro_same.gsc`). Preview because only BO3 was measured. After gscode's `DuplicateMacroDefinition` (GPL-3.0).

## Example

```gsc
#insert scripts\shared\shared.gsh;
#define IS_TRUE( x ) ( x )  // M002: shared.gsh defines it
```

## How to suppress

On the line (or on its own line just above it):

```gsc
#define MAX 4  // gsc: ignore[M002]
```

For a whole file, anywhere in it: `// gsc: ignore-file[M002]`. In `gruff.toml`:
`ignore = ["M002"]`, or `[check.per-file-ignores]` with `"pattern" = ["M002"]`.
