# D004 decompiler-control-flow

## What it does

Reports `goto LOC_1;`, `jumpiffalse( c ) LOC_1;` and `LOC_1:` labels. No game's GSC has them; only decompilers write them, when they cannot rebuild a loop or an `if`.

## Why

The file will not compile. In decompiler output it marks the functions whose control flow needs a manual rewrite.

## Example

```gsc
function f()
{
LOC_1:
    goto LOC_1;   // D004 (twice)
}
```

On a decompiled corpus, `--ignore D004` when it is not the point.

## How to suppress

On the line (or on its own line just above it):

```gsc
goto LOC_1;  // gsc: ignore[D004]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D004]`. In `gruff.toml`:
`ignore = ["D004"]`, or `[check.per-file-ignores]` with `"pattern" = ["D004"]`.
