# N009 constructor-parameters

## What it does

Reports a `constructor` or `destructor` with parameters.

## Why

The BO3 compiler refuses them (syntax error, `lint_ctor_params.gsc`): `new c()` passes nothing. After gscode's `ConstructorHasParameters` (GPL-3.0). Stable: a compiler error.

## Example

```gsc
class c
{
    constructor( a )  // N009
    {
    }
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
constructor( a )  // gsc: ignore[N009]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N009]`. In `gruff.toml`:
`ignore = ["N009"]`, or `[check.per-file-ignores]` with `"pattern" = ["N009"]`.
