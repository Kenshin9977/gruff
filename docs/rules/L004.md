# L004 assignment-as-value

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports an assignment used as a value: in a condition (`if ( x = 1 )`), an argument, an operand. An assignment is only allowed as a statement, a `for` initialiser or a `for` step; parentheses do not change that.

## Why

In a condition it is almost always a mistyped `==`. The BO3 compiler refuses every form, parenthesised or not (`lint_assign_cond.gsc`, `lint_assign_cond_paren.gsc`, `lint_assign_arg.gsc`); Black Ops shipped one (`if ( menu = game["menu_changeclass"] )`), so not every compiler does. After gscode's `AssignmentUsedAsCondition` (GPL-3.0).

## Example

```gsc
if ( menu = game["menu_changeclass"] )  // L004: ==
```

## How to suppress

On the line (or on its own line just above it):

```gsc
if ( x = 1 )  // gsc: ignore[L004]
```

For a whole file, anywhere in it: `// gsc: ignore-file[L004]`. In `gruff.toml`:
`ignore = ["L004"]`, or `[check.per-file-ignores]` with `"pattern" = ["L004"]`.
