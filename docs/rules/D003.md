# D003 import-after-declaration

## What it does

In games that require imports first, reports `#using` or `#insert` after the first declaration.

## Why

The parser accepts the syntax of every Call of Duty game; the dialect check then reports what the selected game (`--game`, or `game` in `gruff.toml`) does not have. The game's compiler would reject it.

## Example

```gsc
function f() {}
#using scripts\shared\util_shared;   // D003
```

## How to suppress

On the line (or on its own line just above it):

```gsc
#using scripts\shared\util_shared;  // gsc: ignore[D003]
```

For a whole file, anywhere in it: `// gsc: ignore-file[D003]`. In `gruff.toml`:
`ignore = ["D003"]`, or `[check.per-file-ignores]` with `"pattern" = ["D003"]`.
