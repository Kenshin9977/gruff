# U001 unused-variable

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a local assigned with `=` (or declared `const`) and never read in its function. Parameters, `foreach` bindings and `waittill` outputs are not reported; a name that appears in the body of a macro the function uses counts as read. Class methods (a bare name may be a member) and decompiler output are skipped.

## Why

A dead store: often a leftover, sometimes a typo in the later read. The BO3 linker accepts it (`lint_unused_local.gsc`). After gscode's `UnusedLocalLint` (GPL-3.0).

Measured: 5,453 findings in the shipped sources (BO3 854, BO1 2,216, MW2 804, WaW 768...); every one sampled is a dead store. The count is why it stays in preview: it is a cleanup rule.

## Example

```gsc
function f()
{
    bmp = spawn_vehicle( "bmp" );  // U001
}
```

## How to suppress

On the line (or on its own line just above it):

```gsc
bmp = spawn_vehicle( "bmp" );  // gsc: ignore[U001]
```

For a whole file, anywhere in it: `// gsc: ignore-file[U001]`. In `gruff.toml`:
`ignore = ["U001"]`, or `[check.per-file-ignores]` with `"pattern" = ["U001"]`.
