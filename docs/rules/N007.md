# N007 misplaced-vararg

## What it does

Reports a parameter after `...`, or a second `...`.

## Why

`...` collects every remaining argument, so a parameter after it can never be bound. The BO3 compiler refuses it (syntax error, `lint_vararg_not_last.gsc`). After gscode's `VarargNotLastParameter` (GPL-3.0). Stable: a compiler error.

## Example

```gsc
function f( ..., last )  // N007
```

## How to suppress

On the line (or on its own line just above it):

```gsc
function f( ..., last )  // gsc: ignore[N007]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N007]`. In `gruff.toml`:
`ignore = ["N007"]`, or `[check.per-file-ignores]` with `"pattern" = ["N007"]`.
