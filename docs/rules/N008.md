# N008 inheritance-cycle

## What it does

Reports a class that inherits from itself through its bases.

## Why

The BO3 compiler refuses it (`lint_class_cycle.gsc`). After gscode's `ClassInheritanceCycle` (GPL-3.0). Stable: a compiler error.

## Example

```gsc
class a : b { }  // N008
class b : a { }
```

## How to suppress

On the line (or on its own line just above it):

```gsc
class a : b  // gsc: ignore[N008]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N008]`. In `gruff.toml`:
`ignore = ["N008"]`, or `[check.per-file-ignores]` with `"pattern" = ["N008"]`.
