# N006 duplicate-parameter

**Preview**: off unless `--preview` (or `preview = true`).

## What it does

Reports a parameter name repeated in one parameter list.

## Why

Only one of the two can be read. The BO3 compiler refuses it ("Duplicate var name in function param list", `lint_dup_param.gsc`), but the IW compilers accept it: MW2's `sab.gsc` ships `onNormalDeath( victim, attacker, lifeId, lifeId )`. After gscode's `DuplicateParameter` (GPL-3.0).

Measured: 23 findings (7 in shipped sources, 16 in decompiler output reproducing the same functions), all real.

## Example

```gsc
function on_death( victim, attacker, id, id )  // N006
```

## How to suppress

On the line (or on its own line just above it):

```gsc
function f( a, a )  // gsc: ignore[N006]
```

For a whole file, anywhere in it: `// gsc: ignore-file[N006]`. In `gruff.toml`:
`ignore = ["N006"]`, or `[check.per-file-ignores]` with `"pattern" = ["N006"]`.
